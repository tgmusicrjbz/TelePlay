# پشتیبان‌گیری و انتقال کمد

این ابزار متادیتای کمد، حساب‌ها، کشوها، فایل‌ها، پلی‌لیست‌ها و تنظیمات را در یک فایل فشرده ذخیره می‌کند. خود فایل‌های رسانه‌ای دوباره دانلود نمی‌شوند؛ آن‌ها در فضای تلگرام باقی می‌مانند و شناسه‌هایشان منتقل می‌شود.

## گرفتن نسخهٔ پشتیبان

در محیطی که `DATABASE_URL` پروژهٔ فعلی تنظیم شده اجرا کن:

```bash
cd backend
python scripts/backup_restore.py export --output komod-backup.json.gz
```

فایل خروجی شامل اطلاعات حساس حساب است و باید مثل رمز عبور نگه‌داری شود.

## انتقال به Railway تازه

1. سرویس و دیتابیس تازه را بساز و متغیرهای محیطی را منتقل کن.
2. یک بار برنامه را اجرا کن تا جدول‌ها ساخته شوند.
3. `DATABASE_URL` دیتابیس تازه را در محیط اجرای ابزار قرار بده.
4. ابتدا فایل را اعتبارسنجی کن:

```bash
python scripts/backup_restore.py import --input komod-backup.json.gz --dry-run
```

5. روی دیتابیس خالی بازیابی را اجرا کن:

```bash
python scripts/backup_restore.py import --input komod-backup.json.gz
```

اگر دیتابیس مقصد دادهٔ آزمایشی دارد و می‌خواهی کاملاً جایگزین شود، فقط پس از اطمینان از آدرس دیتابیس از `--clear` استفاده کن.

بعد از انتقال، دسترسی ربات به کانال‌های ذخیره‌سازی و مقدارهای `TELEGRAM_*`، `JWT_SECRET` و کلید رمزگذاری Gemini را نیز بررسی کن. تغییر `JWT_SECRET` نشست‌های قبلی را از اعتبار می‌اندازد.
