# نقشه راه کمد

این فایل برای تقسیم بهبودها به بسته‌های کوچک و قابل تست است. هر بسته باید کامل، تست و سپس منتشر شود.

## اولویت ۱ — پایداری و اعتماد

- [x] اصلاح Drag & Drop صف پخش و شناسه فایل‌های تکراری
- [x] افزودن Repeat ویدیو بدون شلوغ‌کردن نوار ابزار
- [x] حفظ صف پخش، مورد جاری و Repeat بعد از رفرش برای هر حساب
- [x] پایدارکردن صف‌های لینک، TTS و STT در دیتابیس
- [x] Retry هوشمند، ادامه بعد از ری‌استارت و پاک‌سازی کارهای گیرکرده
- [ ] صفحه سلامت سرویس‌ها برای مدیر

## اولویت ۲ — سرعت پیدا کردن و مدیریت محتوا

- [ ] جست‌وجوی Full Text روی نام، توضیحات، تگ و متن یادداشت‌ها
- [ ] تحمل غلط تایپی و پیشنهاد هنگام جست‌وجو
- [ ] تشخیص فایل تکراری و ساخت میانبر به فایل موجود
- [ ] فیلترهای ذخیره‌شدنی و پوشه‌های هوشمند

## اولویت ۳ — تجربه پخش

- [ ] ذخیره صف‌های دلخواه با نام اختصاصی
- [ ] تاریخچه پخش و ادامه پخش بین دستگاه‌ها
- [ ] Gapless playback و Crossfade اختیاری برای موسیقی
- [ ] ساخت نسخه صوتی کم‌حجم از ویدیو برای حالت «فقط صدا»
- [ ] پیشنهاد پخش بعدی بر اساس پوشه، تگ و سابقه

## اولویت ۴ — آفلاین و همگام‌سازی

- [ ] صف تغییرات آفلاین برای پوشه، تگ و پلی‌لیست
- [ ] حل تعارض نسخه آنلاین و آفلاین
- [ ] بررسی فضای آزاد و تخمین حجم پیش از دانلود
- [ ] همگام‌سازی انتخابی دانلودها بین دستگاه‌ها

## اولویت ۵ — اشتراک‌گذاری و امنیت

- [ ] لینک عمومی با انقضا، رمز و محدودیت مشاهده/دانلود
- [ ] گزارش دسترسی و تاریخچه عملیات مهم
- [ ] نرخ‌دهی درخواست‌ها و هشدار ورود مشکوک
- [ ] خروجی و بازیابی تنظیمات و متادیتای حساب

## اولویت ۶ — کیفیت و نگه‌داری

- [ ] Lazy Load صفحه‌های سنگین و کوچک‌کردن Bundle اولیه
- [ ] ثبت خطا با شناسه قابل پیگیری و داشبورد مدیر
- [ ] ابزار پشتیبان‌گیری و مهاجرت Railway/دیتابیس
- [ ] تست‌های خودکار مسیرهای اصلی موبایل و مینی‌اپ
